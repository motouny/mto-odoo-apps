Features

Live preview

  • A real iframe of the actual login page, not a mock-up
  • Updates instantly as you change any setting
  • Judge the exact look before you save anything

Position & colors

  • Place the login card center, left, right, top or bottom
  • Card background, text and button/link colors
  • Optional welcome title and subtitle, translatable

Background

  • Solid color, two-color gradient with angle, or an uploaded image
  • Optional dark overlay for legible text over images
  • Works whether or not the Website app is installed

Pro mode

  • Inject custom CSS on top of the design above
  • Add an extra HTML panel to the login card (support info, links, notices)
  • Gated to Settings administrators only

Why this app

  • Off by default - Odoo's own login page is completely untouched until you enable it
  • Per-company design, multi-company ready
  • No external dependencies, no other paid app required
  • Arabic/RTL and any installed language supported for welcome text
