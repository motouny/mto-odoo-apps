Login Page Designer - Website Compatibility

Free companion add-on - auto-installs with Website, no manual step

Odoo 18 Free

Companion add-on to Login Page Designer. Once the Website app is installed, it takes over the login page layout to show the site's own header and footer instead of the plain login card. This add-on re-applies the same Login Page Designer design directly on top of that website-driven layout, so the designer keeps working exactly the same way whether or not Website is installed.

Why you need this

  • Installs itself automatically the moment Website is installed alongside Login Page Designer
  • No configuration - the same Settings screen and live preview keep working
  • Hides the site's header/footer for a clean, branded login screen when the designer is enabled
  • Free - part of the Login Page Designer product, not a separate purchase
